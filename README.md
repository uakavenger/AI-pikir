# AI Pikir — пікір реңкін анықтау

Қазақша және орысша қысқа пікірді **оң**, **бейтарап** немесе **теріс** деп болжайтын оқу прототипі. Пайдаланушы мәтін енгізеді; TF‑IDF мәтінді сандық белгілерге айналдырады; Logistic Regression сыныпты болжайды. Streamlit қолданбасы мәтінді файлға сақтамайды.

> Бұл зертханалық демонстрация ғана. Деректер синтетикалық және аз, сондықтан көрсеткіштер нақты пікірлерге таралмайды. Модельді бизнес шешімдеріне қолданбаңыз.

## Жоба ішінде

- `app.py` — Streamlit интерфейсі.
- `data/reviews.csv` — 90 синтетикалық мысал; әр сыныпта 30 жол.
- `src/train_model.py` — деректі тексеру, бекітілген бөлу, бағалау және модельді сақтау.
- `model.joblib` — қолданба жүктейтін, толық дерекпен қайта оқытылған модель.
- `metrics.json`, `evaluation_run.txt` — соңғы оқытудың метрикалары мен тест жолдары.
- `presentation.pptx` — 6 слайдтық қазақша таныстырылым.
- `DEFENSE_GUIDE.md` — сөйлеу мәтіні, демо реті және мұғалімнің сұрақтарына жауаптар.
- `CONTRIBUTION_LOG.md` — оқушының өзі толтыратын жеке үлес журналы.

## Windows жүйесінде іске қосу

Алғашқы рет `setup.bat` файлын ашыңыз. Ол Python 3.11 ортасын құрып, кітапханаларды орнатып, модель мен бағалау файлдарын жасайды. Орнату біткен соң `run_app.bat` файлын ашыңыз. Бағдарлама ашық тұрған терминал терезесін жабу серверді тоқтатады.

Қолмен орнатқыңыз келсе, жоба қалтасында PowerShell ашып, мына командаларды ретімен орындаңыз:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python src/train_model.py
streamlit run app.py --server.address 127.0.0.1
```

Браузер автоматты ашылмаса, `http://localhost:8501` мекенжайына өтіңіз. Сервер тек осы компьютердің өзіне қолжетімді болып бапталған. PowerShell виртуалды ортаны іске қосуға тыйым салса, жаңа PowerShell терезесін ашып, README-дегі командаларды сол жерде орындаңыз немесе бір рет `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` командасын қолдануға болады.

Қолданба бұрыннан бар `model.joblib` файлын пайдаланады. `train_model.py` оны деректермен қайта жасайды әрі бағалау файлын жаңартады. Интернет керек болатын қадам — кітапханаларды алғашқы рет орнату.

Үш тексеруді қайта жүргізу үшін, виртуалды орта белсенді кезде `python -m unittest discover -s tests -v` орындаңыз.

## Бағалау қалай жүргізіледі?

Скрипт деректі 75/25 үлеспен, сыныптардың үлесін сақтап, `random_state=42` арқылы бөледі. Бағалау моделі тек 67 оқыту мысалын көреді. Accuracy, macro-F1, сынып бойынша precision/recall/F1 және confusion matrix тек бөлек ұсталған 23 тест мысалынан есептеледі. Содан кейін қолданбаға арналған екінші модель 90 жолдың бәрімен қайта оқытылады. Тест нәтижесін бүкіл дерекпен оқытылған модельдің нәтижесімен шатастырмаңыз.

Метрикалар әр іске қосқанда `metrics.json` және `evaluation_run.txt` файлдарына жазылады. Соңғы өлшенген нәтижені сол файлдардан қараңыз. Бастапқы іске қосу кезінде accuracy — **39.1%**, macro-F1 — **0.386** болған; бұл төмен нәтиже. Қайта есептелген нәтиже өзгеруі мүмкін, сондықтан слайдтағы мәнді соңғы `metrics.json` файлына сәйкестендіріңіз.

## Әдіс

- **TF‑IDF:** мәтіндегі сөздер мен тіркестерді сандармен көрсетеді; бір және екі сөзден тұратын n-граммаларды қолданады.
- **Logistic Regression:** белгілер негізінде үш сыныптың бірін болжайтын қарапайым, түсіндіруге болатын бастапқы классификатор.
- **Бағалау:** accuracy жалпы дәл болжауды көрсетеді; macro-F1 әр сыныптың F1 мәніне тең салмақ береді. Сыныптар тең болғандықтан, macro-F1 пайдалы қосымша өлшем.

Бұл әдіс мәтіннің астарлы мағынасын түсінбейді. Сөздердің тіркесіне сүйенетіндіктен, терістеу, сарказм және жаңа сөздер кезінде қателесуі мүмкін.

## Деректер, қауіпсіздік және шектеулер

CSV-дегі 90 жол — жобаға қолмен құрастырылған синтетикалық қазақша/орысша мысалдар. Олар шынайы клиент пікірлері емес, пайдаланушыдан жиналмаған және сыртқы дереккөзден алынбаған. Дерек лицензияланған нақты корпус ретінде көрсетілмейді. Пайдаланушы жазған мәтін Streamlit сессиясында өңделеді; кодта оны файлға жазу не сыртқы қызметке жіберу жоқ. Құпия немесе жеке ақпарат енгізбеңіз.

Үлгі шағын әрі синтетикалық болғандықтан, тест бөлігі де небәрі 23 сөйлемнен тұрады. Тілдердің теңгерімі, сөйлем құрылымдары және тақырып ауқымы шектеулі. Нәтиже қазақ және орыс тілдерінің әрқайсысына жеке сапа кепілдігін бермейді; ықтималдық мәні сенімділіктің кепілі емес. Нақты қолдану үшін келісіммен жиналған, өкілді және қолмен белгіленген әлдеқайда үлкен корпус, тіл бойынша бөлек тест және құпиялықты тексеру қажет.

## Көрсетілімге арналған үш мысал

| Енгізілетін пікір | Күтілетін белгі |
|---|---|
| Қызметкерлер сыпайы, бәрі ұнады | Оң (positive) |
| Қызмет әдеттегідей болды | Бейтарап (neutral) |
| Сапасы нашар, қайта алмаймын | Теріс (negative) |

Сақталған модель осы төрт мәтінге тиісінше positive, neutral, negative, negative деп болжайды. Алғашқы үш мәтін деректер жиынының ішінде болғандықтан, олар тек интерфейс демонстрациясы; тәуелсіз бағалау емес. Шынайы бағалау бөлек ұсталған 23 тест мысалынан есептелген. Аралас сөйлем терістеу мен екіұдай мағынаны түсіну қиындығын көрсетеді.

## Қалпына келтіру

Қолданба `model.joblib` таба алмаса, жобаның негізгі қалтасында `python src/train_model.py` орындап, қайтадан `streamlit run app.py` командасын бастаңыз. Кітапхана орнату қатесі шықса, Python 3.11 және белсенді `.venv` таңдалғанын тексеріңіз.
